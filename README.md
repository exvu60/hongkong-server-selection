## 官网首页没写的四件事

这四条在官方文档里写得清清楚楚，但在大部分推荐文里被略过了，而它们恰好会影响你实际用起来顺不顺。

**第一，600 Gbps 防护不是标配。** 首页大字写 “up to 600 Gbps mitigation”，很容易理解成买套餐就自带。官方文档的原话是：所有实例默认提供 **best-effort 基础清洗，免费**；600 Gbps 专业清洗是**付费附加项**，需要联系客服开通。

比这更关键的是黑洞机制。当实例遭受的大规模攻击影响到同网段其他客户时，系统会自动对该 IP 施加 null route，持续 **30–60 分钟**，自动解除，**无法人工干预**。这段时间内进出流量全部丢弃，服务直接不可用。对建站的人来说，这条比“600Gbps”这个数字重要得多：真被打进黑洞，你的站就是半小时到一小时打不开，而且没有任何办法提前解除。

**第二，退款只有一次机会，而且只对新购有效。** 新购 24 小时内可全额退款，每用户限一次，续费订单不适用。到账时间支付宝 1–3 个工作日，信用卡 5–10 个工作日。想靠退款反复试不同套餐是行不通的，24 小时窗口要用在刀刃上——开机后先跑 mtr 确认回程走的是不是 CN2 / 9929 / CMIN2，再决定留不留。
